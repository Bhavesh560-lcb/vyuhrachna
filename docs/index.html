🔗 કોમન ડેટા

પ્રોહીબીશન અને ચોરી બંને વિભાગમાં (તથા એક જ વિભાગના જુદા જુદા કેસમાં) એક જેવા મળતા આરોપીના મોબાઇલ નંબર, IMEI, નામ, વાહન નંબર, વોટ્સએપ, સોશિયલ આઇ.ડી. વગેરે. 🆕 = છેલ્લે જોયા પછી નવો ઉમેરાયેલ / સુધારેલ ડેટા.

🤔 લગભગ સરખા નામ (સ્પેલિંગ ફેર / વચ્ચેનું નામ અલગ)

💡 કોઈ પણ ખાનું ક્લિક કરી સુધારી શકાય છે (સુધારેલાં ખાનાં પીળાં). છેલ્લી કોલમમાં 📤 શેર / PDF, ➕ આરોપીની નવી રો, ↔ બીજા રજીસ્ટરમાં ખસેડો, 🗑️ ડિલીટ. આરોપીની સંખ્યા પર ક્લિક કરતાં આખી યાદી ખુલશે.

🔥 સૌથી વધુ મેચ

🕘 તાજેતરની ફાઇલો

🕸️ સંપર્ક જાળ

કોઈ પણ નામ, મોબાઇલ, IMEI, ગાડી નંબર કે ગુ.ર.નં. લખો. પછી કોણ કોની સાથે સંપર્કમાં છે તે ઝાડ (ટ્રી) રૂપે આપમેળે દેખાશે. B-પાર્ટી → બીજા કેસનો આરોપી → તેના B-પાર્ટી… એમ જેટલા સ્તર મળે એટલા.

👥 અન્ય વ્યક્તિ

જે માણસ પકડાયેલ પણ નથી અને બાકી આરોપી પણ નથી, પણ આરોપીઓ સાથે સંપર્કમાં છે (B-પાર્ટી, સપ્લાયર, વાહન માલિક, સંબંધી…). તેમના નામ, નંબર, IMEI, ગાડી અને ફોટા અહીં ભેગા રાખો. એ સંપર્ક જાળ અને કોમનમાં આપમેળે જોડાશે.

🖼️ ફોટા

આરોપી, ગાડી, ફોન, મુદ્દામાલ, સ્થળ અને દસ્તાવેજના ફોટા. કેસ રજીસ્ટરમાં "🖼️ ફોટા", આરોપીની વિગત, અન્ય વ્યક્તિ અને સંપર્ક જાળમાંથી પણ ઉમેરી શકાય. ફોટા નાના (compress) કરીને આ મોબાઇલ/કમ્પ્યુટરમાં સેવ થાય છે.

Excel / WhatsApp માંથી આખી યાદી કૉપી કરી સીધી પેસ્ટ કરી શકાય.

📩 SMS તપાસ — આરોપીના નંબર → કંપની → રિપ્લાય

① નંબર પસંદ કરો → ② "SMS મોકલો" થી મોબાઇલની Messages એપ ખુલશે, Send દબાવો → ③ કંપનીનો રિપ્લાય આવે ત્યારે Messages માં તેને દબાવી રાખી Share → વ્યૂહરચના કરો (અથવા નીચે પેસ્ટ કરો) → લોકેશન સેવ થશે અને ગુજરાત માં હોય તો 🚨 એલર્ટ આવશે.

🌐 ઓનલાઇન શેરિંગ — બધા એક જ ડેટા જોઈ શકે

તમારા પોતાના Google Firebase પ્રોજેક્ટ સાથે જોડો. જે કોઈ આ જ એપમાં એ જ Firebase config અને ટીમ કોડ નાખશે, તે બધા એક જ કેસ રજીસ્ટર જોશે અને સુધારી શકશે. ફેરફાર તરત બધાને દેખાશે.

પહેલી વાર સેટઅપ કેવી રીતે કરવું?
  1. console.firebase.google.com પર નવો પ્રોજેક્ટ બનાવો → Web app (</>) ઉમેરો → config કૉપી કરો.
  2. Build → Firestore Database → Create database.
  3. Build → Authentication → Sign-in method → Anonymous ચાલુ કરો.
  4. Firestore → Rules માં આ નાખી Publish કરો:
    rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /dataMilan/{team}/{rest=**} {
      allow read, write: if request.auth != null;
    }
  }
}
  5. ટીમના બધા સભ્યોને આ HTML ફાઇલ, config અને ટીમ કોડ આપો. (અથવા ફાઇલની અંદર SHARED_CONFIG માં એક વાર ભરી દો, પછી કોઈએ કંઈ નાખવું નહીં પડે.)

⚠️ આરોપીની અંગત માહિતી છે — ટીમ કોડ અને ફાઇલ ફક્ત અધિકૃત સ્ટાફને જ આપો. મૂળ PDF / ફોટો ફાઇલ ઓનલાઇન જતી નથી, ફક્ત નીકળેલી માહિતી જાય છે.
